# Work Item Research

Research project focused on defining and validating the concept of a **Work Item**:

> A unit of software work optimized for coding agents.

The research aims to determine what characteristics make a unit of work effective for coding agents, under which conditions those characteristics hold, and where additional specification or structure may be necessary.

## Research environment

This repository is intentionally developed using vanilla coding-agent workflows.

During the initial research phase:

- OpenCode is used without Nerv.
- No OpenSpec or SDD framework is initialized.
- No persistent agent-memory system is used.
- No additional work-structuring layer is introduced.

This is intentional to reduce methodological contamination while the Work Item construct is being investigated.
